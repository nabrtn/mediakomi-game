# Медиакоми — игра «Угадай цену квартиры»

Интерактивная игра на данных объявлений Avito по Республике Коми (г. Инта): игроку показывают фотографии реальных квартир из активных объявлений, он угадывает цену бегунком, а после получает реальную цену, разницу, баллы и ссылку на объявление.

## Как играть

1. **10 раундов** — в каждом реальные фото квартиры из активного объявления.
2. Листайте **галерею**, смотрите описание (площадь, этаж, улица).
3. Двигайте **бегунок цены** и нажимайте «Оценить».
4. Получаете: реальную цену, разницу, **баллы за точность** и **ссылку на объявление**.
5. После 10 раундов — вердикт: **Жадный студент**, **Адекватный квартирант** или **Транжира**.

## Балльная система (максимум 100 баллов)

| Ошибка от реальной цены | Баллы |
|---|---|
| ≤ 5% | 10 |
| ≤ 10% | 8 |
| ≤ 20% | 6 |
| ≤ 35% | 4 |
| ≤ 60% | 2 |
| > 60% | 0 |

Вердикт на финале считается по среднему отклонению оценок игрока от реальных цен:
- оценки в среднем **ниже** реальных более чем на 10% → 🧐 **Жадный студент**;
- отклонение **в пределах ±10%** → 🏠 **Адекватный квартирант**;
- оценки в среднем **выше** реальных более чем на 10% → 💸 **Транжира**.

## Структура проекта

```
mediakomi-game/
├── index.html   — разметка (3 экрана: старт, раунд, итоги)
├── styles.css   — стили в духе hse.ru (#012D6E), mobile-first
├── app.js       — логика игры, баллы, вердикты
└── data.js      — 36 лотов (только активные объявления с фото), сгенерирован из CSV
```

Никаких сборок и зависимостей — чистый HTML/CSS/JS. Все лоты выдаются в случайном порядке, по 10 за игру.

## Публикация на GitHub Pages

1. Создайте новый репозиторий на GitHub (например, `mediakomi-game`).
2. Загрузите в него **все четыре файла** из этой папки (проще всего перетащить их в веб-интерфейсе: *Add file → Upload files*).
3. Откройте **Settings → Pages**.
4. В разделе *Build and deployment* выберите:
   - Source: **Deploy from a branch**
   - Branch: **main**, папка: **/(root)**
5. Нажмите **Save** — через минуту игра будет доступна по адресу
   `https://<ваш-логин>.github.io/mediakomi-game/`.

Либо через консоль:

```bash
git init
git add .
git commit -m "Медиакоми: игра про цены квартир в Коми"
git branch -M main
git remote add origin https://github.com/<ваш-логин>/mediakomi-game.git
git push -u origin main
```

и затем включите Pages в настройках репозитория (шаг 3–4 выше).

## Обновление данных

Данные лежат в `data.js` и были сгенерированы из CSV-выгрузки скриптом `_tools/make_data.ps1` (PowerShell). Если появится новая выгрузка — запустите скрипт заново, он отфильтрует объявления без фото и без цены.

Фото отдаются напрямую с CDN Avito (уже оптимизированы, подгружаются лениво — `loading="lazy"`), поэтому игра открывается быстро и не требует скачивания картинок в репозиторий.
